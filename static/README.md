# Static Assets

This folder contains all static assets for the LEAP website.

## Structure

- `logo.png` - Main website logo (should be placed here)
- `downloads/` - Contains downloadable lesson resources (PDFs for educator guides, slide decks, and worksheets)

## Adding Files

1. **Logo**: Place your logo file as `logo.png` in this directory
2. **Downloads**: Place PDF files in the `downloads/` subdirectory following the naming convention in `lessons.json`
